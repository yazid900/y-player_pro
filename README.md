# Yr Player Pro — إدارة القوائم عن بُعد (نسخة 1.0.7)

النظام يعمل بقاعدة بيانات واحدة: التطبيق يسجّل **MAC** و**Device Key** عند أول تشغيل، والموقع يدير **قوائم متعددة** لنفس الجهاز. أي إضافة أو حذف أو تفعيل من الموقع أو من داخل البرنامج يُحفظ في قاعدة البيانات، ويستلمه الطرف الآخر خلال ثوانٍ. لا توجد أوامر تحكم بالجهاز (تشغيل/إيقاف/ملء شاشة) — القوائم فقط.

---

## 1) التجربة المحلية أولاً بـ Laragon (مطلوب قبل الرفع)

### أ) تجهيز قاعدة البيانات

1. شغّل Laragon وتأكد أن MySQL يعمل.
2. أنشئ قاعدة باسم `ibplayer_remote` (من phpMyAdmin أو سطر الأوامر).
3. استورد ملف `schema.sql` (لقاعدة جديدة). إن كانت القاعدة قديمة من نسخة سابقة فاستورد `upgrade.sql` — يمكن إعادة تشغيله بأمان، ويحتفظ بالقائمة القديمة ويحوّلها إلى أول قائمة في الجدول الجديد.

### ب) تجهيز ملفات الموقع محلياً

1. أنشئ مجلداً جديداً: `C:\laragon\www\ibplayer-web` (لا تلمس النسخة القديمة الموجودة في `C:\laragon\www\IbPlayerClone`).
2. انسخ محتويات مجلد `Web` كاملاً إليه.
3. عدّل `config.php` المحلي ليشير إلى قاعدة Laragon:

```php
'db_host' => '127.0.0.1',
'db_name' => 'ibplayer_remote',
'db_user' => 'root',
'db_pass' => '',
'admin_token' => 'local_admin_token',
'whatsapp_number' => '213675556605',
'site_url' => 'http://ibplayer-web.test',
'max_playlists' => 20,
```

4. افحص PHP لغوياً:

```powershell
$php = "C:\laragon\bin\php\php-8.3.36-Win32-vs16-x64\php.exe"
& $php -l C:\laragon\www\ibplayer-web\api.php
```

يجب أن ترى `No syntax errors detected`.

5. شغّل خادم اختبار سريع (أو فعّل الموقع من Laragon مباشرة):

```powershell
& $php -S 127.0.0.1:8099 -t C:\laragon\www\ibplayer-web
```

6. فحص سريع عبر المتصفح أو `curl`:

```text
http://127.0.0.1:8099/api.php?action=config
http://127.0.0.1:8099/login.html
http://127.0.0.1:8099/dashboard.html
```

يجب أن ترى JSON فيه رقم واتساب، وصفحة دخول، ولوحة تعرض «لا توجد قوائم بعد».

7. اختبر التسجيل والقوائم:

```text
POST api.php  action=register&mac=00:11:22:33:44:55&key=ABC123
POST api.php  action=playlist_add&mac=...&key=...&name=My%20M3U&type=m3u&m3u_url=http%3A%2F%2Fexample.com%2Flist.m3u
GET  api.php?action=playlists&mac=...&key=...
POST api.php  action=playlist_activate&mac=...&key=...&id=<playlist-id>
POST api.php  action=playlist_delete&mac=...&key=...&id=<playlist-id>
```

### ج) ربط البرنامج بالنسخة المحلية

في الإعدادات ← «الجهاز والتطبيق» ضع الرابط `http://127.0.0.1:8099` ثم اضغط «تسجيل الجهاز» و«اختبار الاتصال». عند أول تشغيل لجهاز جديد تظهر شاشة التفعيل، وبعد إدخال كود التفعيل (أو الضغط «لاحقاً») تظهر القوائم المسجّلة في قاعدة البيانات داخل صفحة «تغيير قائمة التسجيل».

## 2) الرفع إلى الاستضافة (InfinityFree)

1. أنشئ قاعدة MySQL من لوحة التحكم، ثم افتح phpMyAdmin.
2. استورد `schema.sql` لموقع جديد، أو `upgrade.sql` للموقع الحالي (بعد أخذ نسخة احتياطية).
3. **احتفظ بملف `config.php` المنشور الحالي** وعدّل فقط القيم التي تحتاجها:
   - `admin_token` بكلمة عشوائية قوية.
   - `whatsapp_number` دولياً بدون `+`، مثال `213675556605` — هذا هو الرقم الذي سيظهر في شاشة التفعيل وفي الموقع.
   - `site_url` = `https://yr-player.page.gd`.
   - `max_playlists` = عدد القوائم المسموح للجهاز (افتراضي 20).
4. ارفع إلى `htdocs` الملفات:

```text
index.html
login.html
dashboard.html
api.php
admin.html
schema.sql
upgrade.sql
README_AR.md
RemoteControl.html   (للروابط القديمة فقط)
assets/branding/yr-hero.png   (صورة الهوية — انسخ المجلد assets كاملاً)
```

> لا ترفع نسخة Laragon من `config.php`؛ استخدم ملف الاستضافة المعدّل.

5. تحقق من `https://yr-player.page.gd/api.php?action=config` — يجب أن ترى JSON وليس HTML.

> استضافة InfinityFree تعرض أحياناً تحدي JavaScript (صفحة HTML فيها `slowAES`) بدل JSON. البرنامج 1.0.7 يحلّ هذا التحدي تلقائياً ويضع كوكي `__test` ثم يعيد الطلب، لذلك لا حاجة لأي إعداد إضافي.

## 3) تدفق المستخدم الكامل

1. **أول تشغيل للتطبيق:** يُرسل MAC وDevice Key إلى قاعدة البيانات تلقائياً. تظهر شاشة تفعيل فيها MAC والكود ورابط الموقع وزر واتساب المدير.
2. **التفعيل:** المدير يولّد كوداً من `admin.html` (سنة أو مدى الحياة) بعد الدفع عبر واتساب. المستخدم يدخل الكود داخل التطبيق. يمكنه الضغط «لاحقاً» ثم التفعيل لاحقاً.
3. **الدخول للموقع:** `https://yr-player.page.gd/` → `login.html` → أدخل نفس MAC وDevice Key.
4. **لوحة القوائم:**
   - تعرض كل قوائم الجهاز، والقائمة المفعّلة منها.
   - إضافة قائمة M3U أو Xtream باسم اختياري.
   - تفعيل قائمة، حذف قائمة، وتحديث من قاعدة البيانات.
   - زر واتساب يفتح رقم المدير المضبوط في `config.php`.
5. **من داخل البرنامج:** صفحة «تغيير قائمة التسجيل» تعرض نفس القوائم، وتسمح بالتفعيل والحذف والتحديث، وإضافة قائمة جديدة تُحفظ في قاعدة البيانات أيضاً.
6. عند تفعيل قائمة يزيد رقم النسخة، والبرنامج يسحب القائمة الجديدة ويحدّث القنوات والأفلام والمسلسلات تلقائياً.

> الحساب الذي سُجّل مسبقاً يدخل بشكل طبيعي؛ شاشة التفعيل لا تظهر له لأن الجهاز موجود في قاعدة البيانات.

## 4) ملخص API

| Action | الغرض |
|---|---|
| `config` | إعدادات الموقع ورقم واتساب وعدد القوائم المسموح |
| `register` / `pair` | تسجيل MAC + Device Key وإرجاع `first_launch` وحالة الاشتراك |
| `login` / `logout` | دخول الموقع (يرجع token) وخروج فوري |
| `status` / `playlists` / `playlist` | حالة الجهاز والقوائم كاملة |
| `playlist_get` | قراءة القوائم بجلسة الموقع (token) |
| `playlist_add` / `playlist_update` | إضافة أو تعديل قائمة |
| `playlist_delete` / `playlist_activate` | حذف قائمة أو تفعيلها |
| `playlist_save` | توافق مع اللوحة القديمة؛ يحدّث القائمة المفعّلة |
| `activate` | تفعيل كود اشتراك |
| `generate` / `devices` | للمدير فقط (`admin_token`) |

البرنامج يستخدم MAC + Device Key، والموقع يستخدم `token`، وكلاهما يعمل على نفس صف الجهاز.

## 5) استكشاف الأخطاء

- **`Device not found`**: افتح التطبيق مرة واحدة، أو اضغط «تسجيل الجهاز» في الإعدادات.
- **`Run upgrade.sql`**: لم تُستورد ترقية القوائم المتعددة بعد.
- **`Database connection failed`**: راجع بيانات الاتصال في `config.php`.
- **`"<" is an invalid start of a value`**: الموقع رجّع HTML بدل JSON؛ تأكد من رفع `api.php` الجديد ومن أن رابط `api.php?action=config` يعطي JSON. البرنامج يتعامل مع تحدي InfinityFree تلقائياً، لكن أي صفحة خطأ PHP أخرى ستظهر كنص؛ راجع `error_log`.
- **القوائم لا تظهر في البرنامج**: تأكد من تفعيل الاشتراك، وأن الرابط في الإعدادات هو رابط الموقع الصحيح، واضغط «تحديث من الموقع» في صفحة القوائم.
- **الموقع يعطي ملف `config.php` كنص**: تأكد أن الملف يبدأ بـ `<?php` وأنه يرجع `return [ ... ];` (لا BOM ولا حروف قبل `<?php`).

## 6) ملاحظات

- كل كود اشتراك يُستخدم لمرة واحدة.
- Device Key مشتق من MAC ومحفوظ في التطبيق؛ لا يتغير بإعادة تثبيت البرنامج.
- كل شيء (الأجهزة، القوائم، الأكواد) محفوظ في قاعدة البيانات؛ نسخة `playlist.json` على الجهاز هي مرآة للعمل دون اتصال.
- استخدم HTTPS دائماً على الاستضافة، وغيّر `admin_token` قبل النشر.
- ملفات الموقع منفصلة عن البرنامج؛ تحديث الموقع لا يحتاج إعادة بناء الـ exe.
- صورة الهوية موحّدة بين البرنامج والموقع: `Assets/Branding/yr-hero.png` للتطبيق، و`assets/branding/yr-hero.png` للموقع. استبدل الملفين بنفس الصورة إذا أردت تغييرها، ثم أعد بناء البرنامج وارفع مجلد `assets` للموقع.
- النصوص الترحيبية الجاهزة للتعديل في التطبيق موجودة في `Localization/StringsAr.xaml` و`Localization/StringsEn.xaml` تحت المفاتيح `Brand_*`؛ عدّلها مباشرة دون لمس الواجهة.
- خط الموقع `Tajawal` يُحمّل من Google Fonts مع fallback إلى Tahoma، لذلك لا يتعطل الموقع عند انقطاع الاتصال.
- أيقونة البرنامج: `Assets/Branding/app-icon.ico` (مضبوطة كـ ApplicationIcon و Icon للنوافذ). أيقونة الموقع: `Web/favicon.ico`. استبدلهما معاً إذا أردت هوية أخرى.
- عند فتح البرنامج يتصل بقاعدة البيانات تلقائياً ويسحب القوائم دون الدخول للإعدادات، ويوجد زر «القوائم من قاعدة البيانات» في شريط العنوان للوصول السريع.
- MAC المستخدم هو MAC العتادي الحقيقي للكمبيوتر (مع استبعاد بطاقات VMware/Hyper-V/VPN)، وليس قيمة مولّدة عشوائياً؛ Device Key مشتق منه بشكل ثابت.
- النقر على أي بطاقة قائمة يفعّلها ويفتح المشاهدة فوراً؛ القنوات تُحمّل في الخلفية وتظهر تلقائياً دون انتظار الشاشة.
- شاشة «إضافة قائمة تشغيل」 بنمط Yr Player: قسم Xtream Codes وقسم رابط M3U، بطاقات قوائم مرتبة، شارة «اتصال محمي»، ورمز QR يحمل رابط الموقع مع MAC وDevice Key، مع نسخ القيم بنقرة واحدة.
- أثناء تحميل القنوات يظهر شريط تقدّم حقيقي من 0 إلى 100% مع رسائل الحالة. إذا كان الرابط فارغاً أو بلا قنوات تظهر رسالة واضحة: «الرابط فارغ أو لا يحتوي قنوات...» بدل شاشة فارغة.
- كاش احترافي دائم على القرص في `%APPDATA%\YrPlayerPro\cache` (وليس في الذاكرة فقط): فتح القائمة أو إعادة تشغيل البرنامج يتم من الكاش خلال أجزاء من الثانية دون الرجوع لقاعدة البيانات أو مزوّد القائمة. يُحدَّث الكاش تلقائياً عند تغيّر إصدار القائمة، ويُحذف مع القائمة.
- عند الإقلاع يذهب المستخدم المسجّل والمفعّل مباشرة إلى المشاهدة من الكاش؛ الجهاز الجديد فقط يرى شاشة القوائم/التفعيل.
- تسريع الأداء: جلب تصنيفات Xtream وبياناتها بالتوازي، وتقليل زمن الانتظار وعدد طلبات المزامنة عند الإقلاع.
- **لا توجد أي مهلة زمنية على تحميل القوائم**: لا M3U ولا Xtream. البرنامج يفتح شاشة المشاهدة فوراً ثم ينتظر حتى تظهر كل القنوات مهما كبرت القائمة.
- مزوّد `tv.business-cloud-4.ru` يعمل على المنفذ **8080** (المنفذ 80 مغلق)، و`type=m3u_plus` يرجع رمز 884؛ لذلك تُستخدم بيانات Xtream: السيرفر `http://tv.business-cloud-4.ru:8080` مع username/password. اختُبر فعلياً: 16,440 قناة مباشرة + 68,789 فيلم + 17,835 مسلسل = 103,064 عنصراً، وحُفظت كلها في الكاش خلال 103 ثانية.
- **لا توجد رسالة مهلة إطلاقاً**: إذا تعذّر الاتصال مؤقتاً يبقى شريط التقدّم حياً وتظهر رسالة «جاري الانتظار... سيستمر التحميل تلقائياً حتى تظهر القنوات»، ثم تُعيد المحاولة تلقائياً. الرسالة الواضحة الوحيدة عند الفشل هي «الرابط فارغ أو لا يحتوي قنوات» وتظهر فقط إذا كان الرابط فارغاً فعلاً.
- تحميل تدريجي سطر بسطر بدل نسخ الملف كاملاً في الذاكرة، مع شريط 0→100% وعدد القنوات المتجهّزة أثناء التحميل؛ مناسب لقوائم تتجاوز 80,000 قناة/فيلم/مسلسل.
- عند إضافة قائمة جديدة تُفعّل تلقائياً وتُحفظ **كل قنواتها** في الكاش على الجهاز، وتظهر شارة «محفوظة» على البطاقة. حذف القائمة (من الزر أو من أيقونة الحذف على البطاقة) يحذف القائمة من قاعدة البيانات **ويحذف كاشها من القرص** معاً.
- بطاقات القوائم أصبحت مرتبة فوق نموذج الإضافة بترتيب صحيح للعناوين والشارات (بلا تراكب نصي)، مع زر حذف صغير على كل بطاقة.
- هوية واجهة جديدة: كل الحواف شبه مربّعة (`CornerRadius` 2–3 بكسل) بدل الحواف الدائرية، وأزرار/بطاقات/لوحات بنمط هندسي نظيف.
- الخط الموحّد في التطبيق هو **Tajawal** نفسه المستخدم في الموقع، مضمّن داخل `Assets/Fonts` (Regular + Bold) يعمل دون إنترنت.
- القوائم المنسدلة (ComboBox) أصبحت بتصميم احترافي: حدود حادة، سهم ذهبي، قائمة منسدلة بنفس لون اللوحة، وتحديد أخضر جزائري — بدل مظهر WPF الافتراضي.
- الكاش أصبح ملف JSON مباشر على القرص بلا نسخ نصّي وسيط، و`playlist.json` لم يعد يكرّر قائمة القنوات؛ لذلك لا تتضخّم الإعدادات مع القوائم الضخمة.
- إذا كانت القنوات محفوظة في الكاش فتُستخدم فوراً قبل أي طلب شبكي، فلا يظهر أي انتظار عند العودة لقائمة سبق تحميلها.

## 7) الهوية الجديدة: Yr Player Pro / YRP

- الاسم المعروض في البرنامج والموقع وملفات التثبيت: **Yr Player Pro**، والشعار المختصر: **yrp** (الـ `p` بالذهبي). ملف التنفيذ: `YrPlayerPro.exe`.
- الشعار الجديد مربّع بالكامل: أخضر جزائري `#2BD47D` + ذهبي `#E8B44A` + خلفية `#071A14`، بلا حواف دائرية. الأيقونة `Assets/Branding/app-icon.ico`، وصورة الهوية `Assets/Branding/yr-hero.png`، ونظيرتها للموقع `assets/branding/yr-hero.png`، وأيقونة الموقع `favicon.ico`.
- الخط **Tajawal** مضمّن داخل `Assets/Fonts` للتطبيق، ومحمّل من Google Fonts للموقع؛ لا إنترنت مطلوب لعرض واجهة البرنامج.
- عند الترقية من النسخة القديمة يُنشأ مجلد `%APPDATA%\YrPlayerPro` وتُنسخ إليه تلقائياً إعداداتك و`playlist.json` والكاش من `%APPDATA%\IbPlayerClone` عند أول تشغيل، دون فقدان القنوات المحفوظة.
- للتوافق مع البيانات الموجودة: اسم قاعدة البيانات ما زال `ibplayer_remote`، وملف مشروع Visual Studio ما زال `IbPlayerClone.csproj`، وبادئة Device Key ما زالت `IBPRO|` داخلياً. هذه أسماء تقنية مخفية لا تظهر للمستخدم، وتغييرها يُفقد الجهاز تسجيله أو إعداداته؛ لا تعدّلها.
- Device Key نفسه لم يتغير (`669804` للجهاز التجريبي)، لأنه مشتق من MAC بنفس المعادلة القديمة.

### نسخة تثبيت Windows

- يُنشأ ملف `YrPlayerPro_Setup_v1.0.7.exe` من مجلد الـ publish ذاتي الاحتواء (`self-contained`)، لذلك لا يحتاج المستخدم تثبيت .NET.
- المثبّت يضع البرنامج في `C:\Program Files\Yr Player Pro`، وينشئ اختصاراً في قائمة Start وعلى سطح المكتب (اختياري)، ويزيل البرنامج بالكامل من «إضافة أو إزالة البرامج».
- لإعادة بناء المثبّت: شغّل `build_installer.ps1` ثم `ISCC.exe YrPlayerPro.iss` بعد تثبيت Inno Setup 6.
